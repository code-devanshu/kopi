## Short description

Kopi is a free, open-source clipboard manager for macOS and Windows. It keeps what you copy, so you
can search it and paste it again without leaving the keyboard. It's in alpha, and your history stays
on your computer.

## Long description

Kopi is a free, open-source clipboard manager that runs on both macOS and Windows, with the same
shortcuts and history on each. It keeps text, rich text, links, images, files, colors and code, along
with the app each copy came from. Press ⇧⌘V (Ctrl+Shift+V on Windows) in any app, type to search, and
press Return to paste. Pin the snippets you reuse to pinboards. Your history stays on your computer,
works offline and needs no account, and copies from password managers are skipped. Kopi is in alpha,
so expect some rough edges. Optional end-to-end encrypted sync between your computers is coming soon.

## Features

- **History of everything you copy:** text, rich text, links, images, files, colors and code, with
  the app each one came from.
- **Search as you type,** with filters by kind and app, and a preview of the selected clip.
- **Keyboard-first pasting:** Return pastes into the app you're in, ⌥Return pastes plain text, and
  ⌘1–9 pastes one of the first nine. On Windows, Ctrl does what ⌘ does.
- **Pins and pinboards** for the snippets you reuse.
- **Private by default:** history stays on your computer and needs no account. Kopi skips password
  managers and content marked as concealed, and you can exclude any app.

Coming soon: optional end-to-end encrypted sync between your Mac and Windows computers.

## Notes

- Kopi is an alpha. It's usable every day, but Windows support is the newest and has the most rough
  edges.
- Kopi isn't notarized, so macOS asks you to allow it the first time you open it. The one-line
  install on the website avoids that, and the install guide shows both ways.
